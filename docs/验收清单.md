| # | 指控 | 我的复现 | 修法 | 修后复验 |
|---|---|---|---|---|
| 1 | 没有命令采集器 | 全包写入点 **0** 处 | 新增 `seal run -- <命令>`，写 `commands.jsonl` | `out` 精确等于 `"42\n"`，凭证里 1 条命令 |
| 2 | `seal -- cmd` 不支持 | 输出空、退出码非 0 | 与 `run` 同义 | `seal -- node -e "console.log(7)"` 正常输出 |
| 3 | 链哈希不是签名 | 真实 `50cdd56e…` 与我重算**完全一致** | 新增 ed25519 签名（`keygen`/`sig`/`trust`） | 改正文并重算链哈希 → `不通过 0/1：签名不匹配：凭证被改过`，退出码 1 |

| 5 | 30 分钟窗口静默漏文件 | 2 个文件漏 1 个，无任何告警 | 新增 `--window`，漏检写 `warnings` 并在终端告警 | 输出「注意：另有 1 个文件超出 30 分钟窗口未收录」，receipt.json 有 `warnings` |
| 6 | `.gitignore` 与 README 矛盾 | 两处都写 `seal-out/` | 改成 `seal-out/*` + `!seal-out/receipt.json` | 凭证能入库，命令日志不入库 |
