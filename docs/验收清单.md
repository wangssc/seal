## 一、功能（必须全部亲手跑过）

| # | 验收项 | 怎么验 | 判据 |
|---|---|---|---|
| F1 | 盖章 | 干净目录放 2 个文件，`node bin\seal.js` | 输出「已盖章：2 个文件」，耗时 < 2 秒，生成 receipt.json + receipt.html |
| F2 | 记录命令 | `node bin\seal.js -- <命令>` | receipt.json 的 commands 里有该命令、退出码、耗时、输出摘要 |
| F3 | 失败命令也要记 | 跑一条必然失败的命令（退出码非 0） | 凭证里该条退出码非 0 且标红 |
| F4 | 验真通过 | `verify` | 「通过 N/N」，退出码 0 |
| F5 | 防篡改（文件） | 改文件一个字节再 `verify` | 指出具体文件哈希不一致，退出码 1 |
| F6 | 防篡改（凭证） | 改 receipt.json 里一个字再 `verify` | 「链哈希不一致…凭证正文被改过」，退出码 1 |
| F7 | 链式 | 同目录连续盖两次章 | 第二条凭证 `chain.prev` = 第一条的 `chain.hash` |
| F8 | 接管简报 | `resume` | 打印编号、结论、改了哪些文件、验过什么、下一步、接手提示 |
| F9 | 查看 | `show` | 终端渲染出凭证要点；凭证缺失时不崩、退出码 1 |
| F10 | 零依赖 | 断网、空 node_modules 环境 | 直接可跑，`package.json` 无 dependencies |
| F11 | 跨平台路径 | 路径含空格与中文 | 正常盖章 |
