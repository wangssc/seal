# Seal 一句话介绍（可直接复制转发）

## 一、发群里 / 发给同事（3 句）

> AI 帮你干完活，说「弄好了」，你怎么验？
> 我给这个场景做了个小工具 Seal：敲一条命令，它把「改了哪些文件、跑了哪些命令、每样东西的指纹」打成一张一页纸的凭证，谁想改一个字都验不过。
> 仓库地址见 package.json，Windows 和 Mac 都能跑，不联网、不上传任何东西。

## 二、发朋友圈（2 句，短）

> 让 AI 干活最容易崩的一环不是它不会做，是它说做完了你没法验。
> 做了个小工具 Seal：一条命令出一张可核对的交付凭证，改一个字就露馅。仓库地址见 package.json。

## 三、GitHub 仓库简介（一句话，贴在仓库首页）

> One command turns an agent's work into a verifiable delivery receipt — what changed, what ran, what passed, chained so any edit shows.

## 四、有人问「这跟聊天记录截图有什么不一样」

> 截图能 P，聊天记录能删。这张凭证里每个文件带指纹、每条命令带输出指纹，外面还串一条链——改任何一处，验的时候当场指出来是哪一处对不上。

## 五、坦白话（别人问「靠谱吗」时照实说）

> 它现在能证明「东西从盖章那一刻起没被改过」，证明不了「盖章的人没撒谎」。要防这一层得签名，签名版已经有了（`seal keygen`），但对方要先把你的公钥加进信任列表——这一步得当面给，不能靠邮件。
